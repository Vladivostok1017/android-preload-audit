# 追加处理：应用锁（2026-11-03 14:30 前后）

## 现象
卸载安全中心后，**应用锁**里设置过密码保护的应用全部打不开。

## 原因
HyperOS 的「应用锁」由两段组成：
- 拦截判断在 system_server 的 `miui.security.ISecurityManager`（binder 服务 `security`，序号 327）；
- **锁屏密码验证界面由 `com.miui.securitycenter` 提供**。
把安全中心卸载后，拦截仍在、验证界面却不存在 → 被锁应用无法启动。这是首轮卸载时遗漏的依赖。

## 处理过程
1. 先恢复安全中心（**不带数据清除**，保留原数据）：
   `cmd package install-existing --user 0 com.miui.securitycenter` → 返回 `installed for user: 0`
2. 关闭应用锁总开关（shell 无权修改，必须 root）：
   ```
   su -c "settings put secure access_control_lock_enabled 0"
   ```
   - 处理前：`access_control_lock_enabled=1`，`applock_mask_notify=1`
   - 处理后：`access_control_lock_enabled=0`，`applock_mask_notify` 同步变为 0（说明安全中心服务实时响应了该开关）
3. 随后按要求**再次卸载安全中心**：`pm uninstall -k --user 0 com.miui.securitycenter` → `Success`
   - 卸载后 `pm list packages -u --user 0` 仍可见（可恢复），总开关保持 `0`

## 方法
1. `cmd package install-existing --user 0 com.mobiletools.systemhelper` 恢复组件

## 抓到的东西（`packet-captures\zorn-systemhelper-dm.wo.com.cn.pcap`，54,426 字节）

**TCP**：`192.168.31.33:52516 → 223.111.128.82:18080`

**请求（明文 HTTP，两次）**：

第二次：`Content-Length: 1040`，`sign=` 不同。

**响应**：
- 第 1 次：`HTTP/1.1 200 OK`，`Content-Length: 0`

## 结论
- **方向**：本机 → `dm.wo.com.cn:18080`（**中国联通 DM 平台**，"wo"即联通），上行 POST

# 核查：这些组件能否「把手机收到的包统统转发」？

## 结论：不能。以下都是 APK manifest / 原生库 / 抓包实测的结论，不是推测。

### 1. `com.mobiletools.systemhelper`（app_name = "SystemHelper"，v3.0.1）

**Android 上普通应用获取全量流量的唯一合法途径是 `VpnService`**，需要：
`android.permission.BIND_VPN_SERVICE` + 声明一个带该权限的 `<service>` + 用户手动授权（系统会常驻 VPN 钥匙图标）。

本 APK **manifest 中完全没有** `BIND_VPN_SERVICE` 权限，也没有任何 VPN service 组件。

完整权限清单（manifest 原文）：
```
INTERNET, RECEIVE_BOOT_COMPLETED, ACCESS_FINE_LOCATION, ACCESS_COARSE_LOCATION,
ACCESS_BACKGROUND_LOCATION, READ_EXTERNAL_STORAGE, ACCESS_NETWORK_STATE,
READ_PHONE_STATE, ACCESS_WIFI_STATE, CHANGE_WIFI_STATE, FOREGROUND_SERVICE,

```
→ 只有普通联网 + 读电话状态 + 读应用列表 + 定位 + 存储读取，**没有任何抓包/流量镜像能力**。

原生库只有两个，都是百度定位 SDK：
```
lib/arm64-v8a/libindoor.so
lib/arm64-v8a/liblocSDK8b.so
```
无 tcpdump / libpcap / 代理组件（zip 条目 410 个，无 `pcap|sniff|proxy|mitm` 命中）。

其他关键项：
- `android:usesCleartextTraffic="true"` → 允许明文 HTTP（与其访问 `http://dm.wo.com.cn:18080` 一致）

### 2. `com.bsp.catchlog`（app_name = "Log generator"，sharedUserId=android.uid.system）

**manifest 中没有 INTERNET 权限**（权限为 WRITE_EXTERNAL_STORAGE / SYSTEM_ALERT_WINDOW / WRITE_SECURE_SETTINGS / REBOOT / INTERACT_ACROSS_USERS / ACCESS_MTP 等）→ **物理上无法向外发送任何数据**。

它是本地日志工厂：logcat/kernel/dmesg/modem/Wi-Fi/蓝牙/trace(perfetto)/相机日志导出到 `/sdcard/Xiaomi/offline_log`；甚至还带「触发 kernel panic」「RAM dump 模式」「串口日志」这类产线/QA 诊断开关。无原生 .so，无抓包组件。

### 3. 行为实测（100 秒完整抓包）
- 未触发时：**零流量**
- 手动触发 receiver 后：仅 1 次 `POST /register`，body 约 1KB，无持续上行
- 若是"全量转发"，流量特征应是**长连接 + 持续大量上行**，实测完全不符
