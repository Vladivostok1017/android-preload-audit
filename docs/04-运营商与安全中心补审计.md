## 16.6 与 SystemHelper 的关系

SystemHelper 的目标是 `dm.wo.com.cn`（中国联通 DM 平台），本组件的 action 命名空间为 `dmyk`。两者同属运营商 DM（Device Management）体系：SystemHelper 负责采集与投递，RegService 负责注册、心跳与远端指令执行（含改 APN）。

## 16.7 判定

风险：**高**。

- 以 `android.uid.phone` 身份运行，并集成第三方（亚信）DM SDK
- 同时持有短信收发、特权电话状态、精确定位、APN 写入、全应用枚举权限
- 可被远端指令触发上报应用清单、网络信息、充电与蓝牙状态
- 支持解锁前启动
- 端点为民用第三方域，并提供带类型参数的数据上报接口

未做：动态抓包、dex 级反编译。以上结论来自 manifest 与 dex 中的 action 与端点字面量。

### 代码内出现的业务能力（中文串证据）

```
自注册、预装应用、流量采集、应用采集、充电采集、蓝牙采集、
网络采集、Wifi采集、国际漫游、拍照采集、控制功能、日志检查
本次wifi列表采集列表长度为：、采集流量共找到应用数量：
本次为最后一次重试，不做基站和SIM卡信息完整性校验
触发URL更换、触发增加错误次数、触发规则更换
保存动态更新包、本地不存在，去后台申请、查询动态更新配置信息

参数异常，没有：whitelistconfig
```

其中三条值得单独指出：

1. **「触发URL更换」**：上报地址可由服务端在线更换，静态分析看到的 `fxltsbl.com` 不必然是最终落点。
2. **「基站和SIM卡信息完整性校验」**：上报前会校验基站信息与 SIM 卡信息的完整性，说明基站数据是其上报内容的组成部分。
3. **「保存动态更新包」+「whitelistconfig」**：支持下发动态配置包与白名单，采集范围可被远程调整。

### 行为结论

它是一个**可远程配置的运营商数据采集代理**：SIM 就绪即自注册，此后按服务端开关采集预装应用清单、应用流量、WiFi 列表、蓝牙连接、充电状态、网络信息、以及拍照/快照，并在漫游场景下额外上报（仅限移动卡）；服务端还能指定日志上报的时间窗、更换上报地址、下发动态配置与白名单。

这些能力所需的权限（短信收发、特权电话状态、精确定位、APN 写入、全应用枚举）与 manifest 声明完全对应，说明权限与代码用途一致，不存在与声明无关的越权行为。

未做：动态抓包（组件已卸载），故实际上报频率与真实端点未能复核。

# 十七、安全中心定向逆向（`com.miui.securitycenter`）

## 17.1 此前的审计深度

该组件在第十二章标注为「仅 manifest 级」。实际上此前只读了 1 个类（`SensitiveWordDetectProvider`），其 12674 个业务类**未做逆向**。本章为定向补充。

## 17.2 一处方法论修正：manifest 编码

早期对 `AndroidManifest.xml` 的字符串扫描以 UTF-8 解码，得到全零结果。该 AXML 实际为 **UTF-16LE**：

```
UTF-8  命中 "securitycenter"  →  0
UTF-16 命中 "securitycenter"  →  116
```

此前基于 UTF-8 的 manifest 关键字扫描结论全部无效，已按 UTF-16 重做。

## 17.3 录屏能力核查（对「securitycenter 会录屏」这一说法的验证）

结论：**`com.miui.securitycenter` 本身不具备录屏能力**。它没有媒体投影、视频输出、相机相关权限；dex 中的投影引用来自内嵌的「游戏加速器 / 视频工具箱」录屏功能，属用户主动启动的游戏录制，需系统弹窗授权，且无 `createScreenCaptureIntent` 直接调用。

### 「录屏」说法的真实来源

该描述更可能指向 `com.miui.guardprovider`（应用名正是「**系统安全组件**」，易与「安全中心」混淆）。其权限与文案：

```
MANAGE_MEDIA_PROJECTION
FOREGROUND_SERVICE_MEDIA_PROJECTION
CAPTURE_VIDEO_OUTPUT
CAPTURE_AUDIO_OUTPUT
CAPTURE_VOICE_COMMUNICATION_OUTPUT
RECORD_AUDIO
```

且字符串资源中存在明确的授权提示：

```
ai_guard_permission_request_projection_title:
  "Allow system security components to record screen?"
```

即：录屏能力属于「系统安全组件」（guardprovider）的 AI 视频通话防诈功能，且会向用户弹出授权确认。把这条归于 securitycenter 属对象混淆。
